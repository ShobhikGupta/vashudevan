🔍 Search Functionality Demo

This demo shows how the enhanced search functionality works on the Vashudevan Met Global LLP website.

✨ Features Implemented

  • Deep-linking Search Results: When you search for subproducts, the results show individual subproduct cards that link directly to the specific subproduct on the parent product page.
  • Visual Highlighting: Search terms are highlighted in the results with green highlighting for better visibility.
  • Smooth Navigation: Clicking on a search result takes you directly to the subproduct with smooth scrolling and highlighting.
  • Parent Product Context: Each search result shows which parent product it belongs to with a badge.
  • Interactive Feedback: Hover effects and loading states provide clear user feedback.

🚀 How It Works

1 Search for Products: Type in the search box on the products page (e.g., "copper", "aluminum", "316", "wheels")
2 View Filtered Results: The search shows both main products and individual subproducts that match your search term
3 Click on Subproduct: When you click on a subproduct search result, it takes you directly to that specific subproduct on the parent product page
4 Automatic Highlighting: The target subproduct is automatically highlighted and scrolled into view with a smooth animation

🔧 Technical Implementation

Search Result Card Structure:

<div class="card product subproduct-search-result highlighted"> <a href="product.html?slug=aluminum#6061-truck-wheels-troma"> <figure class="product-figure"> <img src="..." alt="6061 Truck Wheels"> <figcaption>6061 Truck Wheels <span class="highlight">(TROMA)</span></figcaption> </figure> <div class="search-result-indicator"> <span class="search-icon">🔍</span> <span class="search-text">Click to view</span> </div> </a> <div class="product-info"> <div class="parent-product-badge">ALUMINUM</div> </div> </div>

Deep-linking Navigation:

// When user clicks on search result: function navigateToSubproduct(parentSlug, subproductSlug) { // Store subproduct to highlight when page loads sessionStorage.setItem('highlightSubproduct', subproductSlug); // Navigate to parent product page with subproduct anchor window.location.href = `product.html?slug=${parentSlug}#${subproductSlug}`; }

Automatic Highlighting:

// On product page load, check for subproduct to highlight const highlightSubproduct = sessionStorage.getItem('highlightSubproduct'); if (highlightSubproduct) { // Find the subproduct element and highlight it const element = document.querySelector(`[data-subproduct-slug="${highlightSubproduct}"]`); element.classList.add('highlighted-subproduct'); // Smooth scroll to the element element.scrollIntoView({ behavior: 'smooth' }); }

🎨 Visual Enhancements

  • Search Result Cards: Distinct styling with hover effects and visual indicators
  • Highlighting Animation: Smooth 3-second highlight animation when navigating to subproducts
  • Loading States: Visual feedback during search operations
