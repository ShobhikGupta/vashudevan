# Cost Protection and Report Specification

## Cost defaults
The VMG workspace is designed free-first:
- free-only mode ON,
- paid API usage OFF,
- auto-switch paid provider OFF,
- max paid cost/report 0,
- daily/weekly/monthly paid budgets 0,
- application daily company limit 20.

If free provider capacity is exhausted, stop/mark honestly. Do not silently use OpenAI. Provider usage shown from VMG logs is an application-recorded estimate unless provider-authoritative quota data is available.

## Report philosophy

NUMBER → CHANGE → GRAPH → SHORT EXPLANATION → DETAILED TABLE → SOURCE/EVIDENCE.

Report defaults include Executive Summary, Five-Year Financials, Graphs, Evidence Labels, Sources, Information Gaps, Credit Safety, Procurement Opportunity, Competitor Analysis, Management Takeaways, and PDF/DOCX/XLSX.

Do not render empty decorative sections. Financial/compare outputs must expose period/date. “What Changed” compares versions of the same company.
