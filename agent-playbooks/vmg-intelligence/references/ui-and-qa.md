# UI and QA Reference

The current V1 surfaces include Dashboard, New Research, Progress, Companies, Reports, Templates, Compare, Usage, Settings, and Company Profile.

Infrastructure readiness must require database + migrations/security + Vault + private Storage, followed by verified Gemini + Google Search grounding before Resolve/Start is enabled.

Do not prioritize extra animations/cards/typography/templates/providers while real-functionality proof is incomplete.

QA should exercise user workflows in a real browser, not infer success from source code. Browser/CDP is preferred; Playwright is secondary. Use desktop/tablet/mobile viewports where relevant. Refresh/reopen is required for persistence proof.
